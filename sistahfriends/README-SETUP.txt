PHOTO STANDARD
--------------
The homepage hero uses the approved Sistah-Friends image featuring women of color
in the requested mature age range. Low-resolution supporting stock photos were
removed. The Past & Signature Experiences cards now use crisp, text-specific
visual treatments so there are no blurry or age-inappropriate people photos.

GOOGLE APPS SCRIPT
------------------
The included Apps Script contains the Sistah-Friends Spotlight iframe fix using
XFrameOptionsMode.ALLOWALL.

If you have already pasted this latest Apps Script version:
1. Apps Script > Deploy > Manage deployments.
2. Edit the existing Web App deployment.
3. Choose New version.
4. Execute as: Me.
5. Who has access: Anyone.
6. Deploy.
7. Do NOT manually Run doGet() or doPost().
